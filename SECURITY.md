# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | yes |

## Reporting a vulnerability

This project processes local image files with NumPy and Pillow. If you find a
security issue (for example, a malformed image causing a crash or excessive
memory use), please open a private security advisory on GitHub or contact the
maintainers instead of filing a public issue.

Please include:

- the affected version,
- a minimal reproducer (synthetic image if possible),
- the Python and dependency versions.

We will acknowledge valid reports and coordinate a fix and disclosure.
